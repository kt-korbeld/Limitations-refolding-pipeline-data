# Limitations of the refolding pipeline for de novo protein design

The preprint can be found here: https://doi.org/10.64898/2025.12.09.693122 

All non-schematic figures used in the paper are generated with the code in `Plots.ipynb` and saved in `./figures`. Figures used in the SI are saved in `./figures/figures_SI`. The underlying functions are imported from `plotting_analysis.py`. All processed data used to generate the figures is saved in `./data`, and input files and scripts neccesary to rerun the data are saved in `./generate_data`. For each figure, a short explanation regarding what input files, scripts, data, and functions where used to generate the final figures is given in `Plots.ipynb`.
